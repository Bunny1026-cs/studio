# **App Name**: Synapse

## Core Features:

- Student Authentication: Secure student login with university email validation and password recovery.
- Wellness Assessment: Interactive assessment with scoring to identify student wellness needs and potential crisis situations.
- AI Companion Chat: Chat interface offering support via three AI personalities. LLM powered tool recommends counselors.
- Counselor Booking: System for browsing counselor profiles, viewing availability, and booking appointments.
- Psychoeducational Hub: Centralized resource library with articles, audio, and video content on various mental wellness topics.
- Peer Support Forum: Anonymous forum for students to connect, share experiences, and provide support to one another.
- Admin Dashboard: Admin panel for analytics, counselor management, and anonymous student insights.

## Style Guidelines:

- Primary color: Soft blue (#72BCD4) to evoke a sense of calm and trust.
- Background color: Light blue (#E0F7FA) for a clean and peaceful backdrop.
- Accent color: Pale violet (#B39DDB) to highlight key elements and create visual interest.
- Font: 'Inter', a sans-serif font known for its clarity and readability, suitable for both headings and body text.
- Use clean and modern icons to represent different resources and support options.
- Modern, mobile-responsive design using Glassmorphism effects for visual depth.
- Smooth transitions and hover effects to enhance user experience and provide visual feedback.
